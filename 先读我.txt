缓缓 v0.4.0 · 给心一点时间

第一次打开：
1. 右键 ZIP → 提取全部。不要在压缩软件内打开。
2. 把解压出的“缓缓”文件夹放到桌面。
3. 用 Edge 或 Chrome 打开“打开缓缓.html”。无需 Node.js 或联网。
4. 页脚应显示 v0.4.0。

已有旧版：
先在原浏览器的“隐私与数据”下载 JSON 备份，关闭网页和启动器。
把新包“缓缓”文件夹里面的全部内容复制到桌面原“缓缓”文件夹，
合并并替换同名程序文件。不要再套一层“缓缓”文件夹。
使用原浏览器、原打开方式，核对版本和原有记录。
详细步骤见“本地使用说明.md”。

后续更新：
双击“更新缓缓.bat”，按提示备份、关闭应用、按 Enter。
需要能访问 GitHub；不需要管理员权限或 Node.js。
下载校验后备份并更新原位置程序，失败时尝试恢复。
程序备份不包含浏览器记录；JSON 备份请另行保管。

若安装了 Node.js 18+，可双击“打开缓缓.bat”使用固定本机地址。
保留启动窗口，按 Ctrl+C 停止。无需安装 npm 依赖。
文件模式和本机地址的记录不会自动互通，切换前请备份。

本版新增：小行动分步陪伴、可编辑的求助话术、记录心情后的下一步。
已使用 v0.3.0 的用户可直接运行“更新缓缓.bat”，无需手动覆盖。
验收步骤和验证范围见“验收与审查报告.md”。
