# 缓缓 · 给心一点时间

一个关注失恋、分离与关系受伤后自我照顾的中文网页原型，适配手机与电脑。使用 React、TypeScript 和 Vite，无需账号或后端服务。

**Windows 本地下载：[缓缓完整运行包](downloads/huanhuan-windows.zip)**。进入文件页面后，点击工具栏中的 **Download raw file** 下载 ZIP，完整解压后用 Chrome 或 Edge 打开“缓缓”文件夹中的 `打开缓缓.html`。运行包已经包含构建产物，无需先安装 npm 依赖。

## 在个人电脑上预览

下载并解压本地包后，项目文件夹名为“缓缓”，双击其中的 `打开缓缓.html` 即可预览，无需安装依赖。已有 Node.js 18+ 的电脑可以双击对应系统的启动文件，或运行 `npm run start:local`，通过固定本机地址使用应用。

完整说明见 [本地使用说明.md](本地使用说明.md)。开发者可运行 `npm run package:local` 重新构建和生成 `release/缓缓.zip`。

## 开始开发

使用 Node.js 22.12+（当前云环境为 Node.js 24）。在仓库目录运行：

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

在云环境中刷新依赖时，可以用 `npm ci --cache /workspace/.cache/npm` 指定可写缓存。刷新后应重启自己启动的开发服务器，避免继续引用已清理的依赖缓存。

```sh
npm run build       # TypeScript 检查和生产构建，输出到 dist/
npm run preview     # 运行生产构建
npm test            # 浏览器端完整流程与异常场景测试
npm run package:local
npm run verify:local # 对实际运行包进行生产与离线检查
```

测试默认使用云环境已提供的 `/usr/bin/chromium`。其他机器可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定 Chromium 路径；或执行 `npx playwright install chromium` 后，设置该变量为已安装浏览器的可执行文件路径。Playwright 会自动启动开发服务器。

## v0.2.0 功能

- **陪我缓一缓**：按感受提供引导、可暂停的呼吸／感官练习、可选前后感受自评、实际练习时长、练习回顾和下一步行动计划。切到后台会暂停计时，各步骤均可跳过。
- **不寄出的信**：搜索标题／正文、收藏筛选、最近编辑排序、五种写作方向、追加提示、完整编辑与删除。未保存离开、保存失败和多窗口冲突都保留输入。
- **我的小行动**：内置建议、自定义计划、每天完成与撤销、最近七天回顾、自定义行动归档和恢复。归档保留历史名称。
- **心情足迹**：每日心情、可选备注与标签、7／30 天日历及全部记录、编辑历史记录和删除确认。首页更换心情会保留已写的备注。
- **隐私与数据**：JSON 备份下载、导入预检与合并、重复导入去重、本地冲突优先、损坏原记录导出、确认清空。自动读取旧版记录。
- **可靠性**：支持 Web Locks 的浏览器以同源写锁串行保存，多窗口同时操作会读取最新数据；缺少写锁、事务存储或安全加密接口时提示只在一个窗口编辑。启动器会识别版本和构建，避免打开旧包。

## 数据与边界

所有记录保存在当前浏览器的 `localStorage` 和 IndexedDB 中。IndexedDB 保存提交后的事务快照，避免不同窗口的缓存相互覆盖；`localStorage` 保留兼容镜像。本应用没有内容上传、分析追踪、AI 服务或自动跨设备同步。记录和 JSON 备份没有额外加密；共享设备需留意隐私，清除站点数据或结束无痕会话可能导致记录丢失。请通过“隐私与数据”定期备份，移动离线页面或更换打开方式前先备份。存储损坏或写入失败时会提示，避免悄悄覆盖旧记录。

这是自我照顾工具，不提供诊断、治疗或恢复效果保证。应用内提供专业支持说明及求助入口。
