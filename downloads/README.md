# 缓缓 Windows 本地运行包

本目录中的 `huanhuan-windows.zip` 是已经构建的完整项目包。解压后目录名为“缓缓”，包含源码、Windows 启动文件、已有构建和独立离线页面，无需先安装 npm 依赖。

在 GitHub 中下载时，进入 `huanhuan-windows.zip` 文件页面，使用文件工具栏的 **Download raw file** 下载压缩包，然后在 Windows 中右键选择“提取全部”。

第一次体验，请用 Chrome 或 Edge 打开解压后“缓缓”文件夹里的 `打开缓缓.html`。本地服务启动说明见包内的 `先读我.txt` 和 `本地使用说明.md`。

该包不包含 Git 凭据、环境文件、依赖缓存或浏览器个人记录。源码和运行包一旦上传到公开仓库，即可被公众下载。
