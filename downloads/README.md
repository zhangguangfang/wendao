# 缓缓 v0.3.0 Windows 本地运行包

打开 [huanhuan-windows.zip](huanhuan-windows.zip) 文件页，点击工具栏 **Download raw file**（向下箭头）下载。右键 ZIP → 提取全部，再用 Edge／Chrome 打开“缓缓”文件夹里的 `打开缓缓.html`，页脚应显示 v0.3.0。

旧版用户先备份浏览器记录并关闭应用，把解压出的“缓缓”文件夹**内部全部内容**覆盖到桌面原“缓缓”目录，避免套一层同名文件夹。之后可双击 `更新缓缓.bat` 在原位置取得正式版本。完整步骤见[本地使用说明](../本地使用说明.md)。

包内包含完整源码、测试、Windows 更新器、启动文件与构建产物，不包含凭据、依赖缓存或浏览器个人记录。下载无需安装 npm 依赖。

[验收与审查报告](../验收与审查报告.md)提供功能前后对照与验收步骤。[SHA256SUMS.txt](SHA256SUMS.txt)用于手动校验；[update.json](update.json)供本地更新器校验版本、大小及 SHA-256。
